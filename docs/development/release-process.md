# Release Process

1. Update the version and changelog as appropriate.
2. Run formatting, lint, tests, and documentation checks.
3. Review packaging metadata and release notes.
4. Create and push a version tag in the form `vX.Y.Z`.
5. Verify the release workflow's platform artifacts, checksums, and provenance.

See [release packaging](../../packaging/README-release.md) and the [signing policy](../../packaging/signing-policy.md) for details.
